# Archived comparison graphics

These images are retained as historical artifacts. They are under provenance
review and must not be presented as verified current-release comparisons.

The overview image displays model 3.12.0 / 2,484 items while its accompanying
data receipt records model 3.0.0 / 2,835 items. Detailed chart images also use
newer aggregate values than the vector-based statistical panels in their
manifest. The cost chart labels newer versions using timing from older model
hashes. See [evaluation status](../evaluation.md) and [resource scope](../resources.md).

The files, existing scores and cohorts have not been regenerated or changed by
this correction. Their preservation does not resolve the source discrepancy.
